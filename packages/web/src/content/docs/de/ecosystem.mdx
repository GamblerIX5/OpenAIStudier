title: Ökosystem
description: Mit OpenStudier erstellte Projekte und Integrationen.
---

Eine Sammlung von Community-Projekten, die auf OpenStudier basieren.

:::note
Möchten Sie Ihr OpenStudier-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-openstudier](https://github.com/awesome-openstudier/awesome-openstudier) und [openstudier.cafe](https://openstudier.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
