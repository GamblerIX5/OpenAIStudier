A collection of community projects built on OpenStudier.

:::note
Want to add your OpenStudier related project to this list? Submit a PR.
:::

You can also check out [awesome-openstudier](https://github.com/awesome-openstudier/awesome-openstudier) and [openstudier.cafe](https://openstudier.cafe), a community that aggregates the ecosystem and community.
