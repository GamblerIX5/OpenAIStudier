Una colección de proyectos comunitarios construidos en OpenStudier.

:::note
¿Quieres agregar tu proyecto relacionado con OpenStudier a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-openstudier](https://github.com/awesome-openstudier/awesome-openstudier) y [openstudier.cafe](https://openstudier.cafe), una comunidad que agrega el ecosistema y la comunidad.
