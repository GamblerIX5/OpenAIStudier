ชุดโครงการชุมชนที่สร้างขึ้นบน OpenStudier

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenStudier ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-openstudier](https://github.com/awesome-openstudier/awesome-openstudier) และ [openstudier.cafe](https://openstudier.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
